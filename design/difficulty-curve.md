## 목적 (Purpose)

이 문서는 GRID REAPER의 라운드별 기대 난이도를 정의하고, "5분의 밀도" 필라가 실제로 구현되는지 검증하기 위한 기준을 제공한다. Round Escalation 시스템의 수식 출력값을 게임플레이 경험으로 번역하여 플레이테스터, QA, 디자이너가 공통 언어를 갖도록 한다.

## Pillar 정렬

| Pillar | 목표 | 이 문서와의 관계 |
|--------|------|----------------|
| **Pillar 1: 읽으면 이긴다** | 어떤 라운드에서도 패턴을 읽으면 생존 가능 | `SAFE_WIN(R) ≥ 0.45s` 불변 — 모든 라운드에서 반응 시간 보장 |
| **Pillar 2: 5분의 밀도** | 5분 세션이 처음부터 끝까지 긴장감을 유지 | `GATE_PERIOD`가 R1→R13에서 2.0s→1.4s로 점진 감소 + Tier 상승 |
| **Pillar 4: 공정한 죽음** | 죽음이 불공평하게 느껴지지 않는다 | `SAFE_WIN ≥ 0.45s` 불변이 "읽었지만 불가능한 이동"을 원천 차단 |

## 공식 참조

### F-RE-1: GATE_PERIOD 에스컬레이션

```
GATE_PERIOD(R) = max(GATE_PERIOD_FLOOR, GATE_PERIOD_BASE − (R − 1) × GATE_PERIOD_STEP)
```

| 상수 | 기본값 | 안전 범위 |
|------|--------|----------|
| `GATE_PERIOD_BASE` | 2.0s | 고정 |
| `GATE_PERIOD_STEP` | 0.05s/라운드 | 0.03–0.08s |
| `GATE_PERIOD_FLOOR` | 1.4s | **≥ 1.2s 필수** |
| 하한 도달 라운드 | **R13** | `floor(0.6/0.05) + 1` |

### F-RE-4: SAFE_WIN 불변 조건

```
SAFE_WIN(R) = GATE_PERIOD(R) − T_EX     (T_EX = 0.35s)
불변: SAFE_WIN(R) ≥ SAFE_WIN_MIN = 0.45s   모든 R
```

`GATE_PERIOD_FLOOR = 1.4s` → `SAFE_WIN_MIN = 1.4 − 0.35 = 1.05s ≥ 0.45s` ✅

## 라운드별 기대 난이도 표

기본값(`STEP=0.05s`, `FLOOR=1.4s`) 기준. 이 표가 Pillar 2 난이도 루브릭의 정량적 기준이다.

|--------|-------------|---------|----------------------|---------|------|
| R1 | 2.00s | 1.65s | 100 / 0 / 0 | 여유 있음 — 패턴 학습 | 🟢 입문 |
| R2 | 1.95s | 1.60s | 100 / 0 / 0 | 여유 있음 | 🟢 입문 |
| R3 | 1.90s | 1.55s | 100 / 0 / 0 | 여유 있음 | 🟢 입문 |
| R4 | 1.85s | 1.50s | 70 / 30 / 0 | T2 패턴 첫 등장 가능 — 가벼운 긴장감 | 🟡 전환 시작 |
| R5 | 1.80s | 1.45s | 70 / 30 / 0 | 속도 미세 상승 체감 | 🟡 전환 |
| R6 | 1.75s | 1.40s | 70 / 30 / 0 | T2 30% — 간헐적 도전 | 🟡 전환 |
| R7 | 1.70s | 1.35s | 30 / 70 / 0 | **Tier 전환 — T2 주도** | 🟠 중간 |
| R8 | 1.65s | 1.30s | 30 / 70 / 0 | 속도 + 패턴 이중 압박 | 🟠 중간 |
| R9 | 1.60s | 1.25s | 30 / 70 / 0 | 집중력 요구 상승 | 🟠 중간 |
| R10 | 1.55s | 1.20s | 30 / 70 / 0 | 세션 중반 클라이맥스 | 🟠 중간 (고점) |
| R11 | 1.50s | 1.15s | 0 / 60 / 40 | **T3 첫 등장 가능** — 앵커 모먼트 | 🔴 고난이도 |
| R12 | 1.45s | 1.10s | 0 / 60 / 40 | T3 40% — 고도의 집중 필요 | 🔴 고난이도 |
| **R13** | **1.40s** | **1.05s** | 0 / 60 / 40 | **속도 하한 도달 — 최고속** | 🔴 최고속 |
| R14 | 1.40s | 1.05s | 0 / 60 / 40 | 속도 고정, Tier만 에스컬레이션 | 🔴 최고속 |
| **R15+** | **1.40s** | **1.05s** | 0 / 20 / 80 | **T3 80% — 마스터 단계** | ⚫ 마스터 |

> **SAFE_WIN 1.05s**: 반응 시간 0.45s 대비 2.3배 여유 — Pillar 1 "읽으면 이긴다" 계약 R13+ 포함 전 라운드 유지.

## 세션 흐름 (5분 밀도 목표)

Pillar 2 "5분의 밀도"는 **5분 세션 전체에서 긴장감이 유지**되는 것을 의미한다. 이를 달성하려면:

| 구간 | 라운드 | 목표 플레이어 상태 | 검증 방법 |
|------|--------|------------------|---------|
| 진입 (0–60s) | R1–R3 | "이해했다" — 패턴 규칙 체화 | 플레이어가 설명 없이 Goal Cell로 이동 |
| 전환 (60–120s) | R4–R6 | "어? 뭔가 달라졌다" — 무의식적 체감 | 플레이어 이동 타이밍 변화 관찰 |
| 압박 (120–240s) | R7–R12 | "집중해야 한다" — 의식적 집중 | 말수 줄어듦, 화면 응시 증가 |
| 클라이맥스 (240–300s) | R13+ | "극한이다" — 한계 도전 | 사망 또는 최고 집중 상태 |

> **5분 세션 기준 기대 라운드**: 솔로 플레이어 기준 R7–R12 도달이 "정상" 세션. R13+ 도달은 고숙련.
> R5 미만에서 세션 종료 빈발 시 → `GATE_PERIOD_STEP` 상향 검토 (OQ-RE-3 해소 필요).

## 체험 단계 설명 (Player Experience Arc)

### 🟢 입문 단계 (R1–R3)
**플레이어 상태**: "규칙을 배운다"

폭발 경고가 길고 안전 경로가 명확하다. T1 패턴만 등장하므로 게임 언어를 학습하는 단계. 죽음이 드물고, 죽더라도 "내 실수"라는 인식이 명확하다. Pillar 4 "공정한 죽음" 기반 구축.

### 🟡 전환 단계 (R4–R6)
**플레이어 상태**: "어? 뭔가 달라졌다"

GATE_PERIOD가 1.85→1.75s로 줄어 속도가 체감되기 시작한다. T2 패턴이 30% 확률로 등장 — 아직 드물지만 익숙하지 않다. 설계 목표: 플레이어가 의식적으로 알아챌 필요 없이 **손이 먼저** 다름을 느끼는 것.

### 🟠 중간 단계 (R7–R10)
**플레이어 상태**: "집중해야 한다"

T2 패턴이 70%로 주도적이 된다. GATE_PERIOD가 1.70→1.55s — 이 구간의 속도 변화가 가장 급격하다(0.15s 감소). 이 단계에서 탈락자가 가장 많을 것으로 예상. R7에서 Tier 전환 신호(격자 펄스)가 시각적으로 발생.

### 🔴 고난이도 단계 (R11–R14)
**플레이어 상태**: "극한 집중"

R11에서 T3 패턴 첫 등장 — GDD에서 지목한 **앵커 모먼트** 후보. "발이 먼저 움직이는 것을 자각하는 순간". R13에서 GATE_PERIOD 하한 1.4s 도달 — 속도 에스컬레이션 종료.

### ⚫ 마스터 단계 (R15+)
**플레이어 상태**: "패턴 해독이 유일한 무기"

속도는 고정(1.4s). T3 패턴 80% — 난이도가 순수하게 "패턴 독해력"에 의존한다. 이 단계 도달은 고숙련 플레이어의 증명. Pillar 1 "읽으면 이긴다"의 최고 표현.

## 주요 설계 텐션 (Pillar 긴장)

> "난이도 가속 (Pillar 2: 밀도) vs. 읽기 가능성 (Pillar 1: 읽으면 이긴다)"

| 긴장 | 위험 시나리오 | 해소 장치 |
|------|-------------|---------|
| GATE_PERIOD가 너무 빨리 감소 | R6에서 이미 체감 불가 — "읽기 전에 죽음" → Pillar 1 파괴 | `GATE_PERIOD_FLOOR ≥ 1.2s` + `SAFE_WIN_MIN = 0.45s` 불변 |
| Tier 전환이 너무 갑작스러움 | R7 진입 순간 "R6→R7 절벽"으로 플레이어 좌절 | 격자 펄스 시각 신호 + R4–R6에서 30% T2 예고 |
| 고라운드 패턴 반복 (R15+) | 동일 T3 패턴 3개만 순환 → 지루함 | Pattern Library `N_recent = 2` 반복 방지 + OQ-RE-4 해소 필요 |

| 기준 ID | 질문 | 판정 기준 |
|---------|------|---------|
| DC-PT-01 | R1–R3에서 설명 없이 목표 행동을 수행하는가? | 3/3 세션에서 플레이어가 자발적으로 Goal Cell로 이동 |
| DC-PT-02 | R4–R6 구간에서 체감 변화가 있는가? | 2/3 이상 세션에서 플레이어가 "뭔가 달라졌다"는 반응 |
| DC-PT-03 | R7 전환 시 절벽감이 아닌 점진적 상승이 느껴지는가? | R7 직후 사망률이 R6의 3배 이하 (절벽 판정: 3배 초과) |
| DC-PT-04 | R11+ 앵커 모먼트가 발생하는가? | 플레이어 반응 노트 ("발이 먼저 움직였다" 유형 발언) 1회 이상 |
| DC-PT-05 | 5분 세션에서 긴장감이 처음부터 끝까지 유지되는가? | 세션 후 "지루한 구간이 있었다" 응답 0명 |

> **DC-PT-03 판정 상세**: R7 사망률 = (R7 사망 횟수) / (R7 진입 횟수). R6 사망률 대비 3배 초과 시 Tier 가중치 조정 검토 (R4–6 T2 가중치를 40→20%로 완화 후 재검증).

## 튜닝 가이드라인

### 언제 조정하는가

| 플레이테스트 관찰 | 조정 방향 | 주의사항 |
|-----------------|---------|---------|
| "R1–R6이 너무 쉽다 / 지루하다" | `GATE_PERIOD_STEP` 상향 (0.05 → 0.07) | R_floor 조기 도달 → Tier 에스컬레이션이 유일한 후반 긴장감 수단이 됨 |
| "R7 전환이 너무 갑작스럽다" | R4–6 T2 가중치를 40→20%로 완화 | T2 30%→20%는 전환 충격 완화. 30% 이하는 의미 없어질 수 있음 |
| "R13+ 진입 후 게임이 불가능하다" | `GATE_PERIOD_FLOOR` 상향 (1.4 → 1.5s) | **1.2s 미만 절대 설정 금지** — SAFE_WIN_MIN 위반 |
| "R15+에서 패턴이 반복된다" | T3 패턴 추가 (Pattern Library 스프린트) | OQ-RE-4 — MVP 범위 외, Sprint 5+ 대상 |

### 절대 금지 조정

- `GATE_PERIOD_FLOOR < 1.2s` — SAFE_WIN < 0.45s → Pillar 1 파괴
- `GATE_PERIOD_STEP > 0.1s` — R7 이전 하한 도달 → 속도 에스컬레이션 사실상 없음
- Tier 가중치 합 ≠ 100 — 결정론적 선택 불가 (AC-RE-11 위반)
