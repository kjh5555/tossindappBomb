**Status: CONCLUDED — 2026-04-21** | **Recommendation: PROCEED**

## Hypothesis

1. **T_warn=1.8s는 "읽으면 이긴다" 필러를 지킨다** — 패턴 예고 시간이 패턴을 읽고 안전한 칸으로 이동하기에 충분하다.
2. **8방향 스와이프 인식률 ≥85%** — 실기기 터치에서 의도한 방향으로 85% 이상 인식된다.
3. **MOVE_TWEEN_DURATION=0.1s는 즉시 이동으로 느껴진다** — 0.1s 선형 트윈이 지연감 없이 "보는 순간 이미 거기 있다" 판타지를 지킨다.
4. **코어 루프에 "한 판 더" 동기가 발생한다** — 죽고 나서 재시도하고 싶은 충동이 발생한다.

## Result

### Q1 — 경고 시스템
- **최종 결론: 경고 없음이 정답** — W1→W2→IM 단계 전부 제거. IDLE→EX(0.35s)→IDLE.
- 경고 단계는 지루함의 원인. 즉각 폭발 + 짧은 지속이 긴박감을 만든다.

### Q2 — 입력 방식 (OQ-PM-1)
- **스와이프**: 인식률 자연스러움 확인 (PASS)
- **조이스틱**: 스와이프보다 더 자연스러운 연속 이동감. **조이스틱으로 전환 확정.**
- MOVE_REPEAT=0.22s가 적절한 이동 속도.

### Q3 — 트윈 체감 (OQ-PM-3)
- MOVE_TWEEN_DURATION=0.1s: **PASS** — 즉시 이동으로 느껴짐.

### Q4 — 코어 루프 재미
- **"한 판 더" 발생: Yes** — 고정 경로 + 게이트 파도 타이밍이 "패턴을 읽고 최적 경로로 돌파"하는 전략적 재미를 만든다.

## Lessons Learned

- **경고 단계 불필요**: W1→W2→IM 단계는 지루함을 만들 뿐. 즉각 폭발 + 짧은 지속이 긴장감과 공정함을 동시에 달성.
- **자유 이동 vs 고정 경로**: 8×8 전체 자유 이동은 "너무 쉬움"을 만듦. 고정 경로가 전략적 선택을 강제하고 난이도 구조를 만든다.
- **조이스틱 > 스와이프**: 연속 이동이 필요한 게임에서 조이스틱이 스와이프보다 자연스럽다. OQ-PM-1 재해소: 입력 방식 스와이프→조이스틱으로 변경.
- **게이트 파도 타이밍**: stagger offset 0.5s 간격이 "파도처럼 순차 개방"되어 플레이어가 게이트를 연속으로 통과하는 리듬감을 만든다.
- **globalT 지속**: 죽어도 게이트 리듬이 초기화되지 않아 플레이어가 관찰 후 재진입 타이밍을 잡을 수 있다 — "읽으면 이긴다" 필러 유지.
